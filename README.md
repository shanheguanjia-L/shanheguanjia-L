## Projects

### [fit-plan](https://github.com/shanheguanjia-L/fit-plan) · [Try it](https://shanheguanjia-l.github.io/fit-plan/)

A chat-style fitness helper: answer a few questions and get a weekly training plan and a 7-day meal example.
Everything is calculated in the browser — nothing is uploaded. The page is in Simplified Chinese.

健身小助手：回答幾個問題，在手機瀏覽器裡算出每週訓練安排和 7 天飲食示例，資料不上傳。

- Exercise notes and images adapted from [wger](https://wger.de); food data from USDA FoodData Central
- License: code MIT, exercise content and images CC BY-SA 4.0 ([details](https://github.com/shanheguanjia-L/fit-plan/blob/main/LICENSE))
